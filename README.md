# 📘 IT English Vocabulary Learning Platform

一個使用 **Ruby on Rails** 打造的 IT 英文學習平台，  
幫助開發者在閱讀技術文件時，快速提升英文理解能力。

---

## 🚀 Features

### 單字測驗（選擇題）
- 英文單字搭配 4 個中文選項（1 正確 + 3 誘導）
- 誘導選項來自「相同分類 + 相同難度」，提升辨識能力

### ⭐ 收藏單字
- 一鍵收藏常見或重要單字
- 可集中管理個人單字庫

### 🔁 錯誤單字複習
- 自動記錄錯誤單字（去重）
- 顯示錯誤次數與測驗模式
- 支援重新測驗（強化記憶）

### 📊 學習統計儀表板
- 總答題數 / 答對率
- 各分類 / 測驗模式分析
- 最近 7 天學習趨勢

---

## 🛠 Tech Stack

- **Backend**：Ruby on Rails 8.1.2 (Ruby 3.2.4)
- **Database**：MySQL (mysql2)
- **Authentication**：Devise
- **Frontend**：Hotwire (Turbo + Stimulus)
- **Assets**：Importmap + Propshaft
- **Deployment**：Railway

## 🎯 Project Goal

打造一個「工程師導向」的英文學習工具，  
不只是背單字，而是：

- 提升閱讀技術文件能力
- 強化長期記憶（錯題機制）
- 建立個人化英文筆記系統
