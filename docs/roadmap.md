# 開發路線圖

這份文件用來追蹤 IT 英文詞彙學習平台的產品方向與開發順序。

## 目前優先

- 新增 Admin 單字管理後台。
- 改善錯題複習，加入更清楚的「已掌握」流程。

## 下一階段

- 新增每日學習目標。
- 強化 Dashboard，提供更清楚的學習進度分析。
- 新增單字搜尋與分類瀏覽。

## 未來規劃

- 新增間隔複習排程。
- 重新設計 `/quiz` 輸入題測驗流程。
- 新增成就徽章。
- 新增單字資料 CSV 匯入與匯出。
- 新增單字例句或使用情境說明。

## 備註

- 每個較大的功能都應該在 `docs/features/` 底下建立獨立文件。
- 功能優先順序改變時，可以把項目移到不同階段。
- `/quiz` 輸入題目前先暫緩，原因是中文翻譯有多種合理答案，若使用完全比對容易造成誤判與挫折感。
