# 間隔複習

## 目標

根據每位使用者的答題紀錄安排複習時間，讓困難單字更常出現，已掌握單字降低出現頻率。

## 解決問題

錯題複習很有幫助，但目前所有錯題幾乎被同等看待。間隔複習可以讓練習更有效率。

## 功能範圍

- 追蹤使用者下次應該複習某個單字的時間。
- 答對後拉長複習間隔。
- 答錯後縮短或重設複習間隔。
- 新增待複習單字頁面。

## 暫不包含

- 完整複製 Anki 的所有功能。
- 複雜的機器學習排程。
- 通知或 email 提醒。

## 可能資料變更

- 新增 `review_items` table。
- 追蹤 `user_id`、`vocabulary_id`、`next_review_at`、`interval_days`、`correct_streak`、`last_reviewed_at`。

## 可能路由

- `GET /reviews`
- `POST /reviews/:vocabulary_id/answer`

## 實作步驟

1. 設計複習排程規則。
2. 新增 review 相關資料 model。
3. 建立待複習單字查詢邏輯。
4. 新增複習 UI。
5. 每次作答後更新複習狀態。
6. 新增排程行為測試。

## UX 備註

- 第一版排程規則應該保持簡單。
- 讓使用者清楚知道某個單字為什麼出現在複習中。
- 之後可以在 Dashboard 顯示待複習數量。
